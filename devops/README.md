# CódigoFlow DevOps Workspace

Real automation content for Terraform, Ansible, Puppet, and Nagios.

- `terraform/` — AWS working module plus Azure/GCP samples
- `ansible/` — inventories, playbooks, roles
- `puppet/` — manifests, modules, hiera, drift lab
- `nagios/` — objects, plugins, sample status
- `lab/` — optional Vagrant lab and bootstrap scripts

See `docs/` for architecture and setup guides. Backend adapters live under `server/src/devops` and `server/src/integrations`.
